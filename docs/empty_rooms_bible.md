# 《空房间》— 长篇世界观与三卷大纲手册

> 手册用途：可作为长篇创作 bible、AI 写作 prompt、改编衍生作的世界观底稿。
> 设计容量：200 万字。三卷骨架，每卷可装 60-80 万字主线 + 支线。
> 题材定位：都市异能 · 夹缝怪谈 · 记忆悬疑
> 母题：被遗忘的过去如何重塑现在的自己——林知夏是谁？

---

## 第一部分 · 世界观

### 一、世界基底：三岸与夹缝

世界的表象是人间日常，实质由三层拼接而成：

**阳岸（生者岸）** — 即普通人类感知到的现实。包括现代都市、医院、廉租房、街道、灯红酒绿。阳岸的物理规则正常，普通人终其一生不会感知到另外两层。

**阴岸（死者岸）** — 死者执念未消，残存意识栖息之地。不是传统意义的"地府"或"阴司"，而是一片由集体记忆堆叠出的"雾区"。雾区的地形随死者群体记忆变化：老医院旧址记忆深，雾区就有一座雾版医院；战场旧址记忆深，雾区就有一片雾版战壕。雾区没有时间，只有"记忆密度"。

**夹缝走廊** — 阳岸与阴岸之间的褶皱层。不是空间，而是"通道状态"。它只在特定节点（七处旧址之一）打开，开启条件是引魂香 + 引魂人。夹缝走廊不是一条直廊，而是无数个"残室"叠加——每一个残室是某一桩未竟之事的现场复刻。引魂人的工作不是"送魂下地府"，而是走进残室，替死者完成那一桩未竟之事，让残室消散，死者执念才能散开。

**核心矛盾**：夹缝走廊不是为引魂人开的，它是被"三十年前那场事故"撑裂的。原本两岸之间是隔绝的，三十年前的事故让七个旧址同时发生了"夹缝开放未闭"，至今未愈。引魂人不是天选英雄，是事故漏网者之一——他们活下来了，但大脑被夹缝的"记忆渗漏"浸泡，所以失忆、失眠、记忆错位。**所有引魂人都是受害者**。

### 二、核心机制：引魂香体系

引魂香不是"咒语道具"，是一种物理化学与精神共振的合体机制。

**原料** — 用死者生前最执念的物件（头发、骨灰、字迹、最常穿的衣服纤维等）制成。每种香只对一类执念起反应。

**种类**（共九种，后期可扩展）：

| 名 | 用途 | 代价 |
|---|---|---|
| 引魂香 | 打开夹缝走廊入口 | 点香者失眠七日 |
| 安魂香 | 安抚死者执念，让残室软化 | 点香者记忆一段流失 |
| 识脸香 | 让引魂人看见死者最后一眼 | 持续用会面容脱落 |
| 缝魂香 | 把碎裂的死者意识缝合 | 点香者被一段陌生记忆永驻 |
| 忘魂香 | 让死者彻底消散（最 violent） | 点香者的同等记忆被永久删除 |
| 寻路香 | 在夹缝走廊里定位某个残室 | 会吸引走廊里游荡的"无脸人" |
| 锁门香 | 暂时关闭某个夹缝入口 | 该入口对应的死者集体失序 |
| 召旧香 | 召唤三十年前事故中的某个具体死者 | 极度危险，可能召来"非死者" |
| 反魂香 | 禁术。让死者附身引魂人oretarily复活 | 引魂人意识可能被永占 |

**禁忌**：
1. 一根香只对应一个死者。一根香让两个死者进入，两个死者会融合成"无脸人"。
2. 香的点燃时间不能超过一个时辰（2 小时）。超时夹缝不会闭合，阳岸现实会被渗漏。
3. 反魂香、忘魂香、召旧香在"安魂署"内列为禁术，私用者格杀。
4. 同一引魂人身上不能同时存在三种以上"缝魂香驻留记忆"，超过三种人格会碎裂。

### 三、异能分级体系

主角团不是天选之子，是事故漏网者。普通人不会觉醒。引魂人的能力分七级：

**Lv.0 引魂预备** — 失眠、过目不忘、识脸能力。林知夏开篇即在此级。

**Lv.1 起香人** — 能点燃引魂香、安魂香、识脸香三种基础香。代价：失眠加重。→ 林知夏第一卷会达到此级，揭开自己引魂人身份。

**Lv.2 辨相师** — 能识脸至死者生前最后七日的所有面孔，能听见残室里死者的"未完成句"。→ 第二卷中段到达。

**Lv.3 缝魂者** — 能使用缝魂香，接纳死者记忆而不被覆盖，并能在自己脑内"翻阅"缝魂记忆。此级开始可对抗 Lv.4-5 的反派。→ 第二卷末段。

**Lv.4 引魂正执** — 熟练识别夹缝走廊里游荡的"无脸人"，能反向利用无脸人残片作为信息源。能在夹缝走廊中"开门"。→ 第三卷上半段，林知夏揭开自己三十年前生还者身份后觉醒。

**Lv.5 锁门人** — 能使用锁门香、寻路香，能在阳岸直接"封住"某处旧址不再渗漏。每个时代一名。→ 第三卷下半段的对手。

**Lv.6 召旧者 / Lv.7 反魂者** — 禁术级。需要"安魂署"远古老臣子级别才能驾驭。是主角最终要面对的敌人级别。

### 四、组织格局

**安魂署（官方）**
- 隐藏在民政系统的单位。全国分七处署，每处对应一个事故旧址。
- 名义使命：关闭夹缝、维护生者岸秩序、监督引魂人。
- 实质：内外派系分裂。
  - **守门派**（主流）：坚决关闭所有夹缝，认为三十年前事故必须永久封存。主张"忘魂"——让所有 Related 死者彻底消散。
  - **缝魂派**（地下）：主张梳理死者意识，让真相被记录下来。认为守门派在掩盖三十年前的责任。
  - **召旧派**（禁派）：极少数人秘修召旧香和反魂香，试图让三十年前某个关键死者复活，他们相信"那个死者知道真相"。

**民间引魂人** — 散落民间，多为事故漏网者后代。安魂署不承认其合法性，但利用他们做基层引魂工作。

**无脸人** — 不属于任何组织。是被错引的死者融合体。游荡在夹缝走廊里，靠吞食引魂人为生。后期会发现部分无脸人其实是三十年前事故中被掩盖的"未判定死因者"。

**"404住户" / 残童** — 半人半残室的存在。多为三十年前事故中未成年的死者。他们不在任何组织账册上，是夹缝走廊里最神秘的一群。林知夏的"404 小孩"是其一。

### 五、核心历史：三十年前的"七处事故"

设定时间锚：1994 年冬。地点：江城（虚构长江沿岸省会）。

**官方记载**：1994 年 12 月 17 日，江城老城区七处旧址同夜发生大火与塌陷。死亡 234 人，失踪 78 人。事故原因定性为"违规施工引爆地下沼气"。

**真相**：江城老城区七处旧址地下，是清代义庄、民国诊所、建国卫生院的复合旧址群。1960 年代的一次秘密医疗计划（"阿芙蓉计划"——用鸦片类药物诱发濒死体验以探索死后世界）在这七处同步运行，留下了大量"中途死亡"的实验体。三十年后（1994 年），这些实验体在地下的意识残片同时觉醒，引发了"夹缝同步开放"事件——七处旧址同时塌陷，地下实验体的意识涌上阳岸，吞噬了现场大量施工工人，并撕开了夹缝走廊。

**关键秘密**：
- 234 名死者并非全是工人，其中 78 人是地下实验体的后代——他们的死亡是用来"完成仪式"。
- 失踪的 78 人，是被夹缝走廊吞没，一部分成为"无脸人"，一部分活下来成为初代引魂人。
- 林知夏，1994 年事故时 5 岁，是失踪 78 人中唯一年幼幸存者。她被救出后送进孤儿院，记忆被抹除，过目不忘是脑损伤后遗症。
- 袁护士，原是 1960 年代"阿芙蓉计划"的护士，1994 年事故时复活，已经被困夹缝三十年。

### 七、人物阵营

#### 主角团

**林知夏** — 28 岁自由插画师。表象是失眠三年的抑郁青年，实则是 1994 年事故幸存者。过目不忘是她"识脸能力"的变体，失眠是夹缝渗漏的副作用。第一卷末发现自己 = 引魂人；第二卷末发现自己其实是 1994 年事故的生还者（而非路过的孤儿）；第三卷揭开自己父亲是"阿芙蓉计划"的发起者之一。
人物弧线：压抑失忆者 → 被迫觉醒的识脸师 → 自毁式揭露真相的缝魂者。

**袁护士** — 表象五十岁，实则 1960 年代"阿棉花计划"的护士，1994 年事故时复活。她是廉租房 403-405 的房东，负责"监管"林知夏。前期反派，中期发现她也想完成任务，第三卷被发现她实际上是林知夏母亲的护士。
人物弧线：潜伏监视者 → 半敌半友的暗助者 → 同盟。

**404 号住户（残童）** — 七八岁，沉默，戴白帽。是 1994 年事故中死去的 78 个失踪者中最年幼的一个，是林知夏儿时在孤儿院的玩伴"小四"。他不是死者，而是"残室意识体"——他的本体就在残室里，外面走廊出现的只是他在阳岸的投影。
人物弧线：线索给予者 → 林知夏记忆的钥匙 → 第三卷被反派'招旧'。

**许明（安魂署守门派新人）** — 30 岁，安魂署江城分署新人，识字辈第一。表面木讷实则敏感。被派来"观察"林知夏是否觉醒，却暗中观察安魂署守门派的真正立场。
人物弧线：监视者 → 同盟 → 第三卷叛署。

**沈玉楼（民间引魂人前辈）** — 47 岁女性，1994 年事故初代引魂人之一，林知夏前任"403 住户"（上一任住进廉租房的引魂人，失败告终但未死）。她隐居城中村算命谋生，留下半本《引魂笔记》。
人物弧线：缺席导师 → 遗产赠送者 → 第三卷显灵。

#### 反派

**周局长 / 周世昌** — 安魂署江城分署署长，60 岁守门派代表。1994 年事故时是江城消防中队小队长，掩盖真相的第一线。他想永远封存真相，因为"阿芙蓉计划"原始名单里有他父亲。
人物弧线：温和长辈 → 隐性加害者 → 自爆式反派。

**吴寂寒（召旧派首领）** — 神秘老人，自称 1994 年事故中"未死也未曾活"。反魂香的复读者，他想用反魂香让 1960 年代阿棉花计划的"核心实验体"复活——那是他的妻子。
人物弧线：悲剧反派 / 第三卷最终敌。

**无脸人 / 走廊众** — 不属于任何阵营。每次林知夏进夹缝都会遭遇。被错引的死者融合体，靠吃引魂人为生。第三卷揭示部分无脸人是 1994 年 78 名失踪者中"放弃缝魂"的一群。

#### 配角

- **房东老头**（第一卷出现）：表面干瘦老头，实为安魂署观察员，第一卷末"突然死去"被林知夏识破是假死。
- **林知夏的画商老白**：第二卷登场，林知夏画作收藏者，实为民间引魂人的资金网络。
- **林知夏的孤儿院阿姨**：第二卷登场，看起来是慈母，实为安魂署缝魂派的暗线。
- **吴寂寒的助手**：第二卷登场的 17 岁少女，林知夏风格的"反向镜像"，她是被吴寂寒收养的孤儿，忠诚于召旧派。

### 八、贯穿道具与伏笔体系

#### 贯穿道具（一物三次，每次意义不同）

**黄铜香插圆盘**（已在第一章出现）
1. 第一卷第 1 章：匹配床头柜抽屉里的焦痕——林知夏初次怀疑房间异常
2. 第二卷中段：发现其他六处旧址都有同样圆盘——指向统一制式，引出安魂署
3. 第三卷终章：圆盘底面刻字揭示是 1960 年代"阿棉花计划"的实验编号

**画中无脸人**
1. 第一卷第 1 章：404 男人送的画，林知夏以为是威胁
2. 第二卷中段：发现画是"识脸香"的物质载体——只有引魂人能从画中看到死者
3. 第三卷：林知夏自己成为画中人——她把自己的记忆封进一幅画送进夹缝

**速写本**
1. 第一卷：林知夏常带的速写本，里面画过的人脸 = 她送走过的病人
2. 第二卷：速写本能"识脸"——画的瞬间能捕捉死者最后一眼的记忆
3. 第三卷：速写本被焚，林知夏失去所有识脸能力，但解锁缝魂

**白帽**
1. 第一卷：404 小孩的白帽
2. 第二卷：白帽材质和"阿棉花计划"实验体病号服同料
3. 第三卷：白帽下没有头颅，是意识体

#### 长线伏笔（核心伏笔三次渐揭）

- **林知夏为什么记得每一张送走病人的脸？** — 第一卷钩，第二卷暗揭（她是引魂预备），第三卷明揭（她童年记忆被她父亲抹除，"过目不忘"是损伤后的代偿）
- **袁护士为什么对林知夏有暧昧友善？** — 第一卷钩，第二卷揭（袁护士认识林知夏母亲），第三卷全揭（袁护士是林知夏阿姨）
- **404 小孩为什么不说话？** — 第一卷钩，第二卷揭（残童只能用画纸通讯），第三卷揭（他的本体是 1994 年事故中林知夏身边死去的小四）
- **林知夏为什么失眠三年？** — 第二卷揭（夹缝渗漏副作用），第三卷揭（三年前她在画画时不慎画出了"召旧香"图案，撕开了一道小夹缝，从此失眠）
- **安魂署守门派到底在守什么？** — 第三卷全揭：守的是 1960 年代名单，名单上有名字的人（包括周局长父亲）若被翻出，江城当下政治格局会崩盘

#### 伏笔账本（每卷新埋 3-5 条 + 解 2-3 条）

**第一卷埋**：白帽小孩身份 / 袁护士的烟（她抽的烟是民国牌子名"金鼠"）/ 房东老头假死 / 三厘米香插制式 / 林知夏速写本
**第一卷解**：黄铜圆盘 = 引魂香插 / 林知夏为什么过目不忘

**第二卷埋**：六个同级旧址 / 阿棉花计划原始名单 / 安魂署派系斗争 / 林知夏母亲身份 / 召旧派存在
**第二卷解**：林知夏是引魂人 / 1994 年事故真相的浅层

**第三卷埋**：第七处旧址 / 林知夏父亲身份终章 / 召旧香真正后果 / 吴寂寒妻子状态
**第三卷解**：1994 年事故深层真相 / 林知夏童年身份 / 反派全部动机

### 九、世界规则边界（防止魔改，保长篇可写）

1. **死亡不可逆**：引魂人不复活死者。反魂香是禁术，且不能让死者完全复活——只让她的"意识"借引魂人身体 3 小时。任何"复活大团圆"都是禁忌。

2. **夹缝一旦打开不能强关**：锁门香只能延缓，不能根治。三十年前的七处夹缝是永久开放的。这就是为什么引魂人必须一代代接手。

3. **引魂香有原料配额**：原料极稀缺。一种香的原料在全世界可能只有 2-3 份。"无限用香"是不可能的。

4. **不写军人/警察之外的官府力量介入**：安魂署体系内自治，不让武警、军队大规模进入夹缝。这保证故事始终聚焦在引魂人个体身上。

5. **异能不能突破 Lv.7**：最高级即终章。打 boss 不靠战力堆叠，靠真相揭露和选择。

6. **不写"系统/穿越/重生"**：坚持本土都市怪谈基底。林知夏的过去揭示靠"识脸+缝魂"，不靠系统重开。

## 第二部分 · 三卷大纲

**单元长度约定**：每卷约 60-80 万字。每卷分三个阶段(起承转)，每阶段约 200-280 章中分。本大纲只到阶段层，不写每章细纲。

### 第一卷《安神香》

**关键词**：失眠 / 廉租房 / 三厘米香插 / 无脸人 / 觉醒
**核心情绪弧线**：压抑 → 怀疑 → 被迫接受 → 第一次主动出手
**字数预估**：70 万字
**主题**：林知夏从失眠抑郁者，到意识到自己能"看见死者最后一眼"，再到被迫点燃第一根安魂香。

#### 阶段一（压抑期，前约 20 万字）

- 林知夏搬进 403，遇到房东袁护士和 404 住户。
- 失眠加剧，每晚都梦到同一栋废弃医院走廊。
- 走廊里出现住户脸——和她三年临终关怀义工送走的病人一模一样。
- 第一根引魂香"被动"点燃：袁护士故意外出，留下一盒老旧香，林知夏失眠忍不住点了一根。
- 夹缝第一次开启，她走进了"残室"——那是她送走的第一个病人的死亡现场。
- 走廊里出现无脸人，靠她的失眠意识为食。
- 阶段一末段：林知夏被无脸人逼到走廊尽头，404 小孩递给她一幅画纸，画里是"她杀死病人"的画面。梦醒。

#### 阶段二（怀疑期，约 25 万字）

- 林知夏开始查廉租房原址——发现旧址是 1994 年事故 1 号位。
- 她画了一系列"死者最后一眼"，发现画里都有同一张护士背影——袁护士。
- 房东老头"突然死去"。林知夏因为是唯一目击证人被询问，但她识破老头是装死。
- 许明登场，作为"上门查户口的男友身份"接近林知夏。
- 沈玉楼（民间引魂人前辈）留下一半的《引魂笔记》在 403 旧阁楼，林知夏读懂了一半：发现自己可能是引魂人。
- 阶段二末段：袁护士与林知夏正面对峙，揭示自己是安魂署观察员，要"考察"林知夏。她递给林知夏一根真正的引魂香——主动选择是否点燃。

#### 阶段三（觉醒期，约 25 万字）

- 林知夏点燃第一根主动引魂香——进入 404 住户的残室。
- 在残室里完成 404 小孩未竟之事（把一幅画交给某个生者）。**残室消散**。
- 404 小孩消失但留下白帽——道具埋设第二卷。
- 房东老头再次出现，撕破假死，带人来"清除"林知夏。许明反水救她。
- 第一根安魂香点起——让 404 小孩残魂能短暂出现一次，林知夏第一次"识脸"成功。
- 阶段三末段大事件：林知夏发现 1994 年事故名单上有她母亲的名字，而她母亲"并未死在 234 名单里"。
- **第一卷终章钩**：林知夏在速写本上画下她最后送走的病人——画完瞬间发现那张脸是她自己 5 岁的样子。

### 第二卷《识脸人》

**关键词**：阿棉花计划 / 安魂署内斗 / 七处旧址 / 缝魂香 / 母亲身份
**核心情绪弧线**：被卷入 → 调查 → 自我怀疑 → 主动揭真相
**字数预估**：80 万字
**主题**：林知夏全面觉醒为识脸师，介入安魂署内斗，发现自己母亲身份与贽designation。

#### 阶段一（卷入期，约 25 万字）

- 林知夏被许明带进安魂署江城分署。
- 周局长接待她，温和老者模样，但敏锐识脸：他手表底有 1994 年的烧痕。
- 安魂署内部派系斗争首次浮现：守门派 vs 缝魂派在"如何处理林知夏"上争执。
- 第二处旧址（人民医院旧门诊楼）出事。引魂人失踪。林知夏被派去现场识脸。
- 在旧门诊楼残室中，林知夏看到 2 号死者生前的最后一句话："火不是我们自己点的。"
- 她第一次成功"识脸"非亲 dying 者——上一任被吞引魂人。
- 阶段一末段：林知夏发现沈玉楼留下的笔记另一半在 2 号旧址，但被守门派提前烧了。

#### 阶段二（内斗期，约 30 万字）

- 民间引魂人袭击安魂署，要求公开 1994 年事故名单。
- 林知夏被反诬为"内鬼"，与许明一起逃亡。
- 在城中村遇到隐居的民间引魂人圈层，发现他们保存着 1994 年 78 名失踪者的口述史。
- 沈玉楼在第三处旧址（月子中心）显身，但她已经是"残室意识体"——她其实在 1994 年就已经死在夹缝里，只留下了执念。
- 林知夏第一次用缝魂香：接纳沈玉楼的部分记忆到自己脑中。
- **关键翻转**：在沈玉楼的记忆中，林知夏看到自己 5 岁时被一个穿护士服的女人抱着逃出火场——那个护士是袁护士，但当时袁护士应该已经死了 20 年。

#### 阶段三（真相期，约 25 万字）

- 林知夏回 1 号旧址廉租房，找袁护士对峙。
- 袁护士坦白：她是 1960 年代"阿棉花计划"的护士，1994 年因事故复活。她在 1994 年从火场救出 5 岁的林知夏并将其送孤儿院，是因为林知夏的母亲是她的同父异母姐姐。
- 林知夏的母亲身份揭示：她是 1960 年代阿棉花计划的"核心实验体"——代号"火雪"，1994 年事故中她的"夹缝开放"是事故触发源，她是为了让 78 个被实验后代能逃出地下而死。
- 吴寂寒正式登场，召旧派出手，要召出林知夏母亲的意识。
- 林知夏拒绝——她不要母亲复活，她要让母亲真正散去。
- 林知夏在第二处旧址第一次遭遇无脸人群体围攻，识脸能力升至 Lv.3 缝魂者。
- **第二卷终章钩**：林知夏在速写本上画下自己母亲，但画完后她发现画中母亲的怀抱里抱的不是 5 岁的林知夏——而是一个她不认识的男婴。

### 第三卷《缝魂者》

**关键词**：父辈名单 / 反魂香 / 第七处旧址 / 终极选择
**核心情绪弧线**：愤怒 → 揭露 → 抉择 → 主动放下
**字数预估**：80 万字
**主题**：林知夏揭开父亲身份与三十年前责任名单，最终选择"缝"而非"反"——主动接纳被遗忘的过去。

#### 阶段一（愤怒期，约 25 万字）

- 林知夏对袁护士的隐瞒愤怒。两人关系破裂。
- 安魂署守门派开始清剿民间引魂人。周局长下令"清除"林知夏。
- 林知夏与许明彻底转入地下，开始主导民间引魂人反击。
- 第四处旧址（歌舞厅）和第五处旧址（拆迁医院）同步出事，"清除"过程中林知夏被迫用忘魂香——某段记忆被永久删除。代价：她忘了自己画过的最后一张脸。
- 林知夏用忘魂香的代价成为引魂人觉醒的导火索：她的识脸能力升至 Lv.4 引魂正执。
- 在第四处旧址残室里，她第一次见到"无脸人群体"中有意识的个体——能说的话，竟是"我们就是被你忘掉的那些"。
- 阶段一末段：周局长被吴寂寒的助手刺杀。守门派群龙无首，开始内乱。

#### 阶段二（揭露期，约 30 万字）

- 林知夏查周局长的遗物——发现他保留的 1960 年代阿棉花计划原始名单。
- 名单上有她的父亲：**林知夏的父亲不是失踪，而是逃亡**。他在 1960 年代是阿棉花计划的发起者之一，事故后畏罪潜逃到东南亚。林知夏母亲（代号"火雪"）是为了追踪他才进入计划成为核心实验体。
- 吴寂寒的真实身份揭示：他是林知夏父亲当年的同事，他想召的"妻子"也是核心实验体之一——林知夏母亲的师姐。
- 林知夏被夹在吴寂寒和安魂署残党之间，她选择"第三条路"。
- 第六处旧址（养老院）开启，在残室中林知夏第一次见到父亲——他已经死了，残留意识在养老院做义工三十年。
- 父亲意识告诉林知夏：第七处旧址（军管区）才是真正的根——1994 年事故的"引爆点"。
- **关键翻转**：第七处旧址在地下打开——它是一个完整的"反魂香容器"。吴寂寒已经在那里三十年，逐步完成反魂仪轨。

#### 阶段三（抉择期，约 25 万字）

- 林知夏、许明、袁护士、404 小孩（残童）、吴寂寒在第七处旧址地下对峙。
- 吴寂寒成功用反魂香召出妻子的意识——但意识借体的不是他妻子，而是 404 小孩（残童）。他召回了错的人。
- 404 小孩（残童）开始"反转"——他不再安静，开始以吴寂寒妻子的口吻说话。
- 吴寂寒拒绝放手。林知夏必须做选择：
  - 选择 A：用忘魂香让 404 小孩被永久散去。
  - 选择 B：用缝魂香接纳 404 小孩的意识到自己脑中——但 404 小孩其实是她孤儿院玩伴小四，她要接纳自己童年最重要的朋友的死。
  - 选择 C：放走吴寂寒和他的"错妻子"——退出缝魂者身份。
- 林知夏选择 D：她没用任何香。她画了一幅画——把第七处旧址的反魂仪轨画在速写本上，然后用画笔把画撕碎。**这是缝魂者的最高境界——不靠香，只靠"识脸+缝合记忆+主动画下并销毁"**。
- 反魂仪轨被林知夏的画封死。吴寂寒的妻子意识在小四体内散去。吴寂寒中风倒地。
- 小四被解放，最后递给林知夏一幅画：画里是 5 岁的林知夏和母亲在一起。**林知夏终于记起了自己母亲的脸**。
- 404 住户房门终于关上，钥匙挂在门上。

#### 终章

- 林知夏搬出廉租房。
- 袁护士在楼下送行，递给她新的一串钥匙："403 住户换成下任引魂人了。但你想回来敲门随时回来。"
- 404 小孩的白帽留在林知夏的新画室桌上。
- 林知夏开始画新画系列——画那些她已经识过脸但还没送走的死者。
- 最后一行：她从不出门旅行，但每当外地来信，她都会点一根香——安魂署七处分署，每一处都在等她到达。

**第三卷终章钩（为第二部铺垫）**：信件最后一封来自军管区第七处旧址——发信人署名"林知夏父亲"。但林知夏父亲刚刚在第六处旧址散去。这封信是谁写的？

## 第三部分 · 附录

### 一、异能代价表

| 等级 | 能力代表 | 一次代价 | 累积代价 |
|---|---|---|---|
| Lv.0 | 过目不忘、失眠 | — | 失眠3年 |
| Lv.1 起香人 | 引魂/安魂/识脸三基础香 | 失眠7日 | 记忆散段性流失 |
| Lv.2 辨相师 | 识死者最后七日面孔 | 持续脸面疲劳 | 自身面容开始虚化 |
| Lv.3 缝魂者 | 缝接纳死者记忆 | 一段陌生梦 | 体内开始有"第二声音" |
| Lv.4 引魂正执 | 利用无脸人作信息源 | 一次阳岸失神 | 阳岸开始"忘记"引魂人 |
| Lv.5 锁门人 | 封闭旧址 | 一次性吐血 | 缩寿1-5年 |
| Lv.6 召旧者 | 召死者意识 | 永不复死 | 自身开始变成残室 |
| Lv.7 反魂者 | 借体复活 | 自我意识被永占 | 不可逆 |

### 二、写作风格硬约束（直接给 AI 写手用）

- **限知视角**：锁死林知夏此刻感知。她不知道的不写。读者与主角同步获知。
- **身体细节替代情绪词**：禁止"恐惧""悲痛"等抽象词，用身体反应代替。
- **三维度揉进**：每个子事件同时包含"发生了什么 + 主角注意到什么 + 身体怎么回应"。
- **数字承载情感**：三厘米、四十二个住户、78 名失踪、3 小时复生。具体数字替代"很多""很久"。
- **贯穿道具三次规则**：每章必须出现一次贯穿道具，每次意义不同。
- **章末钩子在 13 式内**：突然揭示 / 紧急危机 / 未完成动作 / 身份反转 / 两难抉择 / 神秘物品 / 倒计时 / 承诺威胁 / 离奇消失 / 隐藏含义 / 意象钩子 / 回声钩子 / 留白钩子。
- **性别代词铁律**：林知夏一律"她"，404 小孩一律"其"（不作男女限定），残童不交代性别。
- **不超过三种香同驻**：林知夏身上同时驻留的缝魂记忆上限 = 3。超出人格碎裂。剧情不能违反此规则。
- **死亡不可逆**：结尾不准用反魂香复活任何人。

### 三、不可触碰的禁忌（防止 AI 自由发挥崩盘）

1. 不写穿越、系统、重生。
2. 不写"国家力量大规模介入夹缝"。安魂署体系内自治。
3. 不写跨 Lv.7 战力。
4. 不写林知夏与许明的明言情节超过牵手。感情线让位主线。
5. 不写反派洗白大团圆。吴寂寒是悲剧反派——保留他中风后不知所终。
6. 不用"夙愿""宿命""天选""无上"等词。

### 四、术语词表（统一术语，避免歧义）

- 引魂香 ≠ 安魂香 ≠ 识脸香 ≠ 缝魂香 ≠ 忘魂香 ≠ 寻路香 ≠ 锁门香 ≠ 召旧香 ≠ 反魂香
- 引魂人 ≠ 起香人 ≠ 缝魂者。引魂人是身份，后两者是等级。
- 阳岸 / 阴岸 / 夹缝走廊 = 三层世界
- 残室 = 死者未竟之事的复刻现场
- 无脸人 = 被错引死者融合体
- 残童 / 404 住户 = 残室意识体的阳岸投影
- 安魂署 / 守门派 / 缝魂派 / 召旧派 = 组织与三大派
- 阿棉花计划 = 1960 年代秘密医疗计划（非"阿芙蓉"，名字类似但不同）
- 七处旧址 / 1-7 号 = 1994 年事故七个夹缝地点

### 五、写作执行交接清单

- 本手册 + 上述术语表 = 完整写作 prompt 上下文
- 新章节作者/AI 写手只需遵守此手册风格约束，不需读代码
- 建议喂手册时按章节拆解：先喂"第一部分·世界观"，让模型消化后再喂"第二部分·对应卷大纲"
- 细化章节细纲时，请遵循：每章 3000-5000 字 / 章末必有钩子 / 每章至少 1 个贯穿道具出现 / 每章至少 1 个数字承载情感
