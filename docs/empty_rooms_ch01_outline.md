# 第一章《403室的安神香与无脸画》细纲

> 接续手册：`empty_rooms_bible.md`
> 章节性质：全书开篇钩章 / 第一卷第一阶段首章
> 目标字数：3500-4500 字
> POV：锁死林知夏"此刻感知"（深度限知）
> 阅读目标：读者读完这一章，必须想知道两件事——这房子到底怎么了 / 这个女人为什么失眠到病态

---

## 一、章节定位

- 母题：被遗忘的过去如何重塑现在的自己 → **本章不揭，只埋第一道钩**
- 主线钩：林知夏搬入 403，发现 404 不该有人
- 写作目标：让读者相信"林知夏的失眠和过目不忘是真的、这房子真的有问题、她真的在压抑下崩溃"
- 节奏：单章内三拍——**沉→异→破**。
  - 沉：前 1500 字，生活质感（搬家/失眠/洗衣物/点香），靠细节绷住读者
  - 异：中段 1500 字，物件不对（香焦痕、画中无脸人、走廊关门声），从怀疑升级到对峙
  - 破：末段 500-800 字，章末钩子 = 翻转揭示类
- 不写：袁护士出场对白 > 3 句（她是第一卷末才正式登场的反派，本章只惊鸿一瞥）
- 不写：林知夏童年孤儿院、母亲、医生身份相关信息——这是第二卷才揭的伏笔
- **重要**：无脸人在本章只出现 **1 次**（画中）。不要让它在卧室、镜子、走廊各出现一次——意象一次比四次更惧

---

## 二、场景架构

整章 4 个场景，场景切换以"林知夏的空间移动"为锚，不平移到他人内心。

| # | 场景 | 字数 | 密度 | 功能 |
|---|---|---|---|---|
| S1 | 403客厅·傍晚搬入 | ~1000 | 中 | 道具铺陈，安神香出现，引入失眠 |
| S2 | 403卧室·午夜 | ~1200 | 密 | 焦痕+黄铜圆盘匹配，林知夏第一次"触发"验证机制 |
| S3 | 走廊·凌晨2-3点 | ~1000 | 中 | 邻居404男人送画，对话克制，留下画 |
| S4 | 403卧室·天亮前 | ~500 | 密 | 拆画，章末钩子爆发 |

## 三、Beat 列表

### Beat 1（S1·搬入）— 约 600 字 — 密度：中

- **描述**：林知夏扛着最后的纸箱进 403，跟房东袁护士交接钥匙。袁护士交给她一盒十二根的安神香，说"治失眠"。
- **功能**：场景+人物+核心道具（安神香）一次性铺齐
- **动作链**：纸箱落地 → 鞋底蹭墙皮 → 钥匙扔鞋柜 → 袁护士递香时手指凉 → 走廊声控灯熄 → 防盗门合
- **数字承载**：**十二根香** / **403室** / **下午三点**被对面筒子楼挡光
- **身体细节**：袁护士指节凉，林知夏没问"为什么这么凉"——但读者要感觉到主角注意到了
- **林知夏主观偏差**：袁护士站在阴影里，林知夏记得她手腕有一条蜈蚣样旧疤，但她"没看清就当没看清"
- **禁止**：不要让袁护士说出任何带剧情信息的话——她只说"香能助眠，香头燃尽再睡"这一句

### Beat 2（S1·搬入续）— 约 400 字 — 密度：疏

- **描述**：林知夏开始拆纸箱。拆到第二箱时发现一件黑色外套不属于自己。
- **功能**：把"这不是我的东西"埋成第一道不安钩
- **动作链**：撕胶带 → 美工刀声 → 衣物抖开 → 檀香味 → 外套口袋掉出**黄铜圆盘** → 砸在地板上闷响
- **数字承载**：圆盘直径**三厘米**，正好等于市面上罕见香插规格
- **林知夏反应链**：捡起圆盘 → 掂量 → 走到床头柜 → 拉开抽屉 → 见底板有暗黄色焦痕印记 → 测量圆盘吻合焦痕
- **章末钩伏笔**：抽屉里焦痕是**已有圆盘烧过留下的**——意味着搬进来之前 / 更早 / 不是林知夏 放的香
- **禁止**：林知夏不感到惊恐，只是"胸口压了一点东西"，按正常程序继续拆箱

### Beat 3（S2·午夜卧室）— 约 600 字 — 密度：密

- **描述**：林知夏点燃第一根安神香。躺在床上数失眠时辰。香头红点在黑暗里明灭。
- **功能**：正式引入引魂香的"机制不对"——香灰不断、灰烬弯曲
- **动作链**：剥包装 → 香插放圆盘 → 火机咔哒 → 火星舔香头 → 舌根泛酸 → 嗅到甜腻混消毒液 → 看香头 → 数秒数 → 数到第7段时听到滴水声
- **核心异常**：香已烧了四分之三，七厘米的香灰**没断**，弯曲悬空像一截灰白指骨
- **身体细节**：林知夏伸手碰香灰 → 不是粉末，是硬的塑料质感 → 指腹一捏，**七厘米香灰碎成三块**，叮一声落托盘
- **林知夏主观判断**："不是香。是蜡壳裹的红色棉线。"她没恐惧，她识破了——这是道具，不是香
- **数字承载**：**七厘米**香灰 / 棉线浸油脂 / **凌晨两点十七分**（手机屏幕）
- **心理活动**（用身体动作代替）：拿起手机看了时间，放下时把手机壳在水洗被子角落擦了两下。这个擦的动作是她强迫症的表现——埋第一卷阶段三"她其实已经被夹缝渗漏浸过三年"的伏笔

### Beat 4（S2·午夜续）— 约 600 字 — 密度：密

- **描述**：林知夏推断这盒香的真相。翻包装盒底。生产日期模糊，但凭过目不忘能提取出来。
- **功能**：把"香不是新的"推向"香是在 1994 年 12 月生产的"。暗示廉租房 403 之外有人——三十年前的某个西北房间里的人，曾用同款香做同样的事
- **动作链**：拿纸盒 → 翻底 → 生产日期模糊 → 脑海提取 0.1秒捕捉的数字 → **2004年10月14日** → 比"二十年前"的焦痕时间还晚十年 → 但包装材质明显是 1990 年代工艺
- **思考流到中断**：林知夏正要进一步推断 → 听见走廊声控灯亮了又灭 → 有人脚步
- **关键判断**：林知夏没动手。她没把香丢垃圾桶。她把那截红色棉线安神香**收进了速写本夹层**（贯穿道具第二次出现：从"睡眠辅助"变"她自己保留的物证"）
- **林知夏的性格暴露**：她不报警不退租。她画的职业训练让她用"现场勘查"逻辑生活——画过死者最后一眼的人，对物的偏差极度敏感

### Beat 5（S3·走廊·凌晨3点）— 约 700 字 — 密度：密

- **描述**：林知夏因失眠出门透气。走廊。404 门开一条缝。一个黑雨衣男人手里捧着一幅画，请她搭手把画挂上墙。
- **功能**：送画 = 引入无脸人意象的第一眼
- **动作链**：林知夏推门 → 声控灯延迟亮起 → 404 门缝 → 黑雨衣男人背影 → 鞋是黑色布鞋 → 男人请她帮抬画框 → 林知夏托画框底部，**重量不对**（油画+木框最多两三斤，这幅七八斤像夹了铅板）→ 画框背面左下角有凸起 → 林知夏指腹摩挲 → 是"044"三个字 → 挂上墙 → 男人推门走人 → 林知夏独自面对画
- **关键对白**（全章只此一处对话，3 句以内）：
  - 男人："你屋里点的那种香，叫引魂。"
  - 男人："点错了位置，就招了不该看的过来。"
  - 男人推门前最后一字："画挂上，它就不进你屋了。"
- **不写**：不要让男人解释什么是引魂、什么是无脸人。他要让林知夏（和读者）拿着这三个名词回去自己查
- **数字承载**：044 → 但应该是 404 → 林知夏抬头看门牌的瞬间，她意识到三个字写反了
- **身体细节**：林知夏托画框时小臂肌酸——这不是普通画框的重量——后来用第三卷揭它夹了反魂仪轨残纸
- **林知夏性格暴露**：和男人对话时她不抢话不追问。她记下了三个名词，回屋才去查 —— 这是受过临终关怀义工训练的人面对临终者的语气
- **林知夏性别铁律**：**全章林知夏一律"她"**，不许"他"。男人 / 袁护士不重复主语

### Beat 6（S4·拆画）— 约 500 字 — 密度：密

- **描述**：林知夏把画搬进 403。手机手电筒打光。她拆开画框背板。
- **功能**：揭出无脸人意象的第一眼 + 章末翻转钩
- **动作链**：关门 → 锁保险链 → 画框平放在饭桌 → 手电打光 → 画面是 403 卧室一模一样的构图（灰墙、掉漆木门、白被单床），但床沿边站着一个穿灰色寿衣的人——**没有脸**，面部是一片平滑肤色 → 林知夏用指甲掐画框边缘 → 想撕画布 → 指甲碰画中无脸人位置 → **画纸温热** → 缩手
- **不写**：画的来源解释 / 无脸人是什么 / 男人是谁——全留到第2-3章
- **禁止**：让无脸人"动一下"或"裂出眼睛"——本章不要任何动态异象。让读者自我脑补。读者脑补的恐惧比作者写出的更惧

### Beat 7（S4·章末钩）— 约 200-400 字 — 密度：密

- **描述**：章末翻转钩子——身份反转式
- **动作链**：林知夏平静两秒 → 翻画框背板 → 背板左下角 044 三个字是**用颜料写的**，未干 → 用拇指抹了一下 → 颜料化开 → 才看清是 **404**，被林知夏自己看反了 → 翻画框正面 → **画中无脸人手里举的线香已经断了**（不是她想象里"举着"，是"已经举完了一支"）→ 想起房东微信里说过的："404 住户上周搬走了，你千万别去敲那扇门"但门口现在还摆着雨天的鞋子

- **章末钩（身份反转式）**：
  > 林知夏把画翻过来，背板最底部另有一行字，用同款暗红色颜料写的，未干透：
  > 
  > "403 住户——你搬进来之前，404 空了整整三十年。"
  > 
  > 她抬头看自己刚关上的防盗门。门牌号是403。门外走廊对面的404门牌上，**贴着一张她没注意过的招租启事**——招租的联系电话，是她自己刚用那个月刚换掉的手机号码。
- **读者脑中应留的两个问**：(1) 404 是空的还是不空的？（2）林知夏搬进来之前这间屋子里住的是谁？
- **不许触发的**：不要让无脸人实体出现在房间。这一章的意象顶峰就是画

## 六、本章写作硬约束（直接给写手）

- **性别铁律**：林知夏一律"她"。袁护士一律"她"。其它未明 "其"。
- **章末钩13式**：身份反转式。读者脑里不允许出现"那是什么"，必须出现"那不是我以为的"。
- **数字承载情感**：本章用到的具体数字 = 12（根香）/ 3（厘米）/ 7（厘米灰）/ 044/404（号码）/ 凌晨2:17 / 2004-10-14 / 三十年前。每个数字都承载剧情信号，禁止出现"很多""了很久""一会儿"。
- **三维度揉进**：每个 beat 必须同时包含 "发生了什么 + 林知夏注意到什么 + 她身体怎么回应" 三层，不按层分段写。
- **节奏**：一动后必静，一静后可动。Beat 3 写完伸手触灰后必静 1 段呼吸，再起 Beat 4。Beat 5 走廊对话后必回静一段把画搬进屋再起 Beat 6。
- **对话标签 < 50%**：全章对话只 Beat 5 一处，3 句。用动作替代"男人说"——"画后传来一句闷音"。
- **意象密度**：无脸人出现 **1 次**，禁止镜中、卧室、走廊三次重复。一旦重复，章后自查并删第二、三次。
- **禁止词**：心碎 / 恐惧 / 悲伤 / 夙愿 / 宿命 / 天选 / 颤抖 / 浑身发冷 / 后背发凉。用具体身体动作代替。
- **禁止标点**：省略号和破折号禁用。改用句号、逗号、短句或动作断句。
- **禁止**：大段环境铺垫超过 80 字。开篇前 100 字必须 ≥ 3 个事件（搬入/钥匙/声控灯/香）。
- **禁止总结独白**：不写"她意识到这房子不对劲"这样的内心总结。
- **坚持用具象细节**：抽屉焦痕 / 圆盘吻合 / 香灰弯曲 / 颜料未干 / 招租启事上的旧号码——用物证代替情绪。

## 七、本章不允许做的事

1. 不能让夹缝走廊在第一章开放（开在第二卷末）
2. 不能让无脸人在第一章动（开在第二卷第8章）
3. 不能揭袁护士是引魂人 / 安魂署 / 反派身份（揭在第一卷末）
4. 不能揭林知夏是 1994 年事故幸存者（揭在第二卷末）
5. 不能让 404 男人再次出场（第二卷第3号旧址才再出现，他不是 404 真住户）
6. 不能写"林知夏童年记忆闪回"——她失忆，没童年记忆可闪
7. 不能写情绪总结句，不许出现"她感到害怕"
