# 世界观设定

## 时代背景
2020年代的现代都市，表面与普通世界无异。但在东华大学的老图书馆地下，隐藏着一个「深渊图书馆」——一个由历代书行者用意识力量构建的异空间。

## 核心设定

### 深渊图书馆
- 一个无限延伸的地下图书馆，每本书都是一个独立的「书中世界」
- 书籍按危险等级分为：白书（安全）、灰书（有一定危险）、黑书（极度危险）、禁忌之书（不可触碰）
- 书行者可以进入书中世界冒险，获得书中的「知识结晶」，增强自身能力
- 书中世界的时间流速与现实不同：现实中1小时 ≈ 书中1天

### 书行者
- 能够感知并进入书中世界的特殊人类，极为罕见
- 能力等级：初醒 → 通读 → 精读 → 著书 → 焚书
- 每次穿越消耗精神力，过度使用会导致「书蚀」——意识被书中世界同化

### 禁忌之书
- 深渊图书馆最深处封印的一本无名黑书
- 传说作者在写完最后一页时从现实中「消失」了
- 上一任书行者（林默的父母）试图销毁它，但失败了
- 书中的世界正在缓慢向现实渗透

## 关键地点
- 东华大学老图书馆: 建于民国时期，外表破旧，地下藏着整个深渊图书馆
- 阅读大厅: 书行者穿越书中世界的入口，中央有一盏永不熄灭的「守夜灯」
- 禁书区: 地下七层，收纳灰书和黑书，普通书行者不得擅入
- 深渊阶梯: 图书馆最深处，向下延伸不知尽头，据说尽头就是禁忌之书

## 力量体系
- 知识结晶: 完成书中世界的任务后获得，分为记忆/理解/创造/毁灭四种
- 书页: 书行者的灵魂具象化，每页记录一个能力，初醒者只有1页
- 书蚀: 使用力量的代价，侵蚀程度超过50%会失去自我意识
