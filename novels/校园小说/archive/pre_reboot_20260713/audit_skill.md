# Novel Audit Skill — 小说管线审计层

## 位置

三层协作架构中的审计层：

```
设计层 (用户)  →  创意决策、角色设定、每章反馈
审计层 (本skill) →  引导编写、管线执行、5类审查、精确修复
执行层 (LLM管线)→  Architect → Director → Writer → Quality → Ledger
```

## 触发条件

在写过第一章之后，每章工作时触发。触发词：`下一章`、`写第N章`、`继续`。

## 工作流

### Phase 1: 规划

读 project.json 确认当前章节在 chapter_blocks 中的位置、对应锚点事件、角色状态。

确定本章核心事件——必须是一个**可视觉化的校园小事**（停车棚修车、走廊交接棒、操场试跑），不是一个抽象情绪。

### Phase 2: 编写引导

**职责边界（强制）**：`guidance/chapter_NN.md` 是给 Writer 的轻量创作契约，不是审稿报告。不得把下文“5 类根因”的检查项、禁用词长名单、字数行数预算、物件溯源表或示例修复台词原样注入 Writer；它们只在 Phase 4 对生成稿审计时使用。Writer 同时接收多份账本与计划，过多硬约束会使正文退化为逐项执行的分镜清单。

Writer 引导控制在 250 字以内，只保留：本章一个校园事件、人物各自想要什么、必须发生的一次对话转折、一个关系变化，以及不超过 3 条绝对事实禁令。具体台词、动作步骤和结尾身体细节留给 Writer 自行完成。

编写引导前先读取 `guidance/WRITING_STANDARD.md`；正文风格基准以 `reference_benchmark.txt` 为准。

写两个文件：

**outline.md** — 轻量级，给 Architect 用：
```
## 第N章
- 定位: setup / progression / climax
- 目标情绪: X→Y→Z
- 开篇钩子: 一个画面
- 内容概要: 3-5句
- 结尾钩子: 一个画面
- 任务描述: 本章核心 + 关键约束
```

**guidance/chapter_NN.md** — 重量级，给 Writer 用。必须包含 5 类防缺陷指令。模板见下方。

### Phase 3: 执行

```powershell
$env:PYTHONPATH = "repo_root"
python -u scripts/novel_cli.py seed "novels\项目名"
python -u scripts/novel_cli.py plan "novels\项目名" N
python -u scripts/novel_cli.py write "novels\项目名" N --stream
```

### Phase 4: 审计

管线产出正文后，按 5 类根因逐项审查。发现问题 → 直接修文件。修完后等待用户确认。

## 5 类根因审计框架

### 根因 1: 荒谬度 — LLM 默认走安全文本

**为什么发生**：LLM 底层倾向是产出合理、平稳、不出错的对话。搞笑需要荒谬和风险，而荒谬文本在训练数据中是少数。

**检查方法**：角色的推脱/玩笑/自嘲——能被一个正常人在日常对话中当真使用吗？
- 能当真 → 不够荒谬
- 没人会当真 → 及格

**典型失败**：
| 坏 | 为什么失败 |
|----|-----------|
| "我跑步不行，会拖后腿" | 真实存在的推脱理由 |
| "那天风速好，前面的人带了我一段" | 体育课常见的合理解释 |
| "我体育课以保存体力为主" | 老师听了会点头 |

**典型成功**：
| 好 | 为什么成功 |
|----|-----------|
| "我后面追着一只蜜蜂，动力来源不可复制" | 没人会拿这个当真理由 |
| "我手汗严重，经手的东西会生锈" | 逻辑自洽但完全荒诞 |
| "我上次接东西是我妈扔过来的拖鞋，准确率不到30%" | 扯淡但有细节 |
| "交接棒对双方BMI有基本要求，咱俩差距太大" | 用伪科学包装的荒谬 |

**修复方法**：引导文件写死荒谬标杆——直接给出角色该说的荒诞台词，不写"请让角色更搞笑"。写"陈默的推脱必须是：①逻辑自洽的伪科学 ②过度具体的个人经历 ③或对现场规则的荒谬较真"。

**引导模板**：
```
### 荒谬度
- 推脱理由必须是荒谬的，让角色没法接话
- 禁止：能力不足、身体不适、没有经验（正常人的正常理由）
- 必须：伪科学、过度具体、荒谬较真
- 示例台词：[写2-3句本章适用的荒诞台词]
```

---

### 根因 2: 角色行为底线 — LLM 不预测读者情绪

**为什么发生**：LLM 逐章生成，不模拟"读者读完这行会不会讨厌这个角色"。它只看到任务要求"达成目的"，于是选最有效的手段——没意识到某些手段会摧毁角色好感度。

**检查方法**：角色的某个行为——弹幕会不会刷屏骂她？
- 会 → 不能写
- 读者会笑 → 及格

**典型失败**：
| 角色 | 坏 | 为什么失败 |
|------|-----|-----------|
| 赵小麦 | "我把螺丝刀还给三班，告诉他们车铃是谁拆的" | 告密。刚建立的共犯信任被摧毁。读者好感度断崖 |
| 赵小麦 | 全程"埋脸→苍白→低声"不间断 | 读者会对一个只会低头的人失去兴趣 |
| 陈默 | "我觉得这样不对" | 陈默不可以用严肃陈述表达关心，必须用玩笑包装 |

**典型成功**：
| 角色 | 好 | 为什么成功 |
|------|-----|-----------|
| 赵小麦 | "我已经跟体育老师说高二三班陈默自愿替补了。你现在反悔，就是让我撒谎。" | 用"让她自己难堪"来逼迫，不是"让对方难堪"。读者笑她笨，不讨厌她 |
| 赵小麦 | 危机后"声音恢复体委响亮"："你刚才那些话是不是平时没少骗人？" | 元气属性释放，不再是低头怪 |

**修复方法**：每个女主的引导里必须有**禁止清单**，覆盖绝对不能做的事。

**引导模板**：
```
### 行为底线 — 禁止清单
- 赵小麦禁止：告密、出卖、求人、撒娇、得意地笑、说"你真棒"
- 赵小麦必须：每章至少一次元气释放（声音亮起/主动动作/嘴硬反驳）
- 赵小麦紧张时：[当前章的紧张习惯]
```

### 根因 3: 密度膨胀 — LLM 不知道什么时候停

**为什么发生**：LLM 被要求"用动作代替心理描写"后，机械地把每个动作写成一行。被要求"展示角色能力"后，把每个步骤都展开说明。它没有"读者会跳过这段"的判断力。

**检查方法**：这段如果三行还没进入下一拍 — 读者已经跳了。给你的判断标准：
- 动作连写三行没有对话打断 → 密度警告
- 纯技术描述（型号、步骤、参数）超过一行 → 膨胀
- 配角开口超过两句没有推动剧情 → 注水

**典型失败**：
| 坏 | 膨胀了什么 |
|----|-----------|
| Ch1 弹簧歪了→卡扣还在→掰正→垫片放哪→螺丝长短→拧两圈→嘎吱→换短螺丝→一颗一颗(300字) | 自行车维修手册 |
| Ch2 周远被赵小麦逮去跑接力→跑完转学了→周远是搬家→因为跑太多不想回家了(6行) | 与主线无关的脱口秀垫场 |

**典型成功**：
| 好 | 为什么成功 |
|----|-----------|
| Ch3 "咔哒。弹簧弹回去，铃舌清脆响了一声" | 一个拟声词替代三句说明 |
| Ch3 王磊"好接""更好接了" | 每句≤5字，推动节奏不膨胀 |
| Ch4 跑步15行 | 百米本来就只有15秒，形式匹配内容 |

**修复方法**：引导给字数预算，不给详细指令。"修车动作≤5行" > "写清楚弹簧怎么修"。

**引导模板**：
```
### 密度预算
- [场景A] ≤ N行
- [场景B] ≤ M行  
- 配角台词每句≤X字
- 禁止：纯技术描述超过一行、路人反应群像
```

### 根因 4: 钩子重复 — LLM 不理解"反复出现"≠"反复一样"

**为什么发生**：LLM 记住了贯穿物件，于是复用。但它不理解第一天的惊喜就是第二天的疲劳。贯穿物件的正确用法是每次以不同的感官、不同的身体部位、不同的情绪面目出现。

**检查方法**：结尾的物件/感官/身体部位——和最近一章相同吗？
- 相同 → 疲劳，换
- 不同 → 及格

**典型失败**：
| 章 | 结尾 | 问题 |
|----|------|------|
| Ch1 | "螺丝硌着指节，冰凉的。他没意识到自己在笑" | — |
| Ch2 | "兜里的螺丝硌了一下大腿" | 同一物件、同一触感、同一语义位面。重复。 |

**典型成功**：
| 章 | 结尾 | 为什么不同 |
|----|------|-----------|
| Ch1 | 螺丝 + 触觉 + 笑 | 物件钩子 |
| Ch2 | 折痕 + 报名表 | 动作钩子（无意识的行为后果） |
| Ch3 | 铅笔进兜 + 没问同意 | 占有钩子（无意识的占有欲） |
| Ch4 | 看自己虎口 + 没有指甲印 | 模仿钩子（无意识的身体同步） |

**修复方法**：引导里直接禁前两章的钩子方式。这个禁止清单不是束缚，是逼 LLM 找新的身体语言。

**引导模板**：
```
### 钩子 — 禁止复用
- 禁止：螺丝、折痕、硌、冰凉的、他没意识到自己在笑
- 禁止：笔杆触感、体温
- 必须：[本章新物件/新感官]
```

---

### 根因 5: 物件来源 — LLM 不追踪状态变化的因果链

**为什么发生**：LLM 写"新咬痕"时只考虑"这是她紧张的习惯"，不检查"这个具体的咬痕是在本章哪个场景、谁、什么动作造成的"。它不追踪因果，只追踪统计关联。

**检查方法**：本章任何一个**新出现的状态变化**（咬痕/污渍/裂痕/指甲印/数字/折角）——往前追溯：文中第几段、谁、在什么场景下、做了什么动作导致了这个变化？
- 找到源头 → 通过
- 找不到 → 逻辑漏洞，修复

**典型失败**：
| 坏 | 为什么失败 |
|----|-----------|
| Ch3 "笔杆上多了两道咬痕。新的，边缘带着湿，还没干" | 铅笔在陈默手里，赵小麦写数字用圆珠笔。没咬过。找不出咬的动作 |
| 谁换了车铃？ | 跨度三章以上的状态变化也需要源头 |

**典型成功**：
| 好 | 为什么可追溯 |
|----|-------------|
| Ch3 "笔杆上多了两道指甲掐过的印子。握笔时掐出来的" | 掐的动作→指腹→笔杆。因果链完整 |
| Ch4 黄色铅笔 "从箱子最底层夹层里抽出" | 来源明确。后面她知道粉铅笔"丢了"——因为源头清楚，说谎也可信 |
| Ch4 掐虎口 跑步中首现 | L69 第一次出现（无意识）→ L117 第二次改敲箱盖（有意识控制）→ 结尾陈默看自己虎口（模仿） |

**修复方法**：终审时对所有新状态变化做溯源。每个新状态必须能在文中找到对应的触发动作。如果找不到 → 要么加动作，要么换状态类型。

**引导模板**：
```
### 物件来源 — 每件必溯源
- [新物件A] 来源：[谁/在哪/什么动作引入]
- [新物件B] 来源：[同上]
- [新习惯C] 首现位置：[段落位置]
- 禁止出现无来源的物件、无铺垫的习惯
```

## 引导文件全模板

```markdown
# 第N章 专项引导

## 章节定位
- 标题:
- POV:
- 场景:
- 活跃角色:

## 情节锚点（按顺序）
### 1. 开场
### 2. 冲突
### 3. 转折
### 4. 收束
### 5. 钩子

## 5 类防缺陷

### 1. 荒谬度
- 禁止的正常理由: [...]
- 必须的荒谬理由: [...]
- 示例台词: [...]

### 2. 行为底线
- [角色] 禁止: 告密、求人、撒娇、得意笑
- [角色] 必须: 每章一次元气释放
- [角色] 紧张时: [新习惯]

### 3. 密度预算
- [场景] ≤ N行
- 配角台词: ≤ M句, ≤ X字/句
- 禁止: 技术说明超过一行、路人反应群像

### 4. 钩子禁止
- 禁止复用: [最近两章的钩子物件/感官]
- 必须用: [新物件/新感官]

### 5. 物件来源
- [物件A] → [从哪里来]
- [新习惯B] → [首次出现段落]
- 禁止: 无来源的物件、无铺垫的习惯

## 通用禁止
- 沈溪不登场、不提及（第1-7章适用）
- 禁用词: 微微、轻轻、忽然、突然、其实
- 内心独白 ≤ 1句
- 禁止: AI式比喻（"像春风拂过""仿佛命运交织"）
```

# 完整一章的工作流

## 审计检查清单（每章终审时逐条走）

```
□ 荒谬度：角色的推脱/玩笑，能在日常对话中当真吗？
□ 行为底线：女主的每个行为，弹幕会骂吗？
□ 密度：有三行以上没有对话打断的连续动作吗？
□ 钩子：结尾物件/感官和最近两章重复吗？
□ 物件来源：新咬痕/污渍/印记，往前能找到触发动作吗？
□ 数学/时间线：成绩数字、日期、年龄，前后一致吗？
□ 跨章物件：螺丝/报名表/铅笔/秒表，出现方式有变化吗？
□ 禁用词：微微/轻轻/忽然/突然/其实，扫一遍？
□ 沈溪禁令：前7章不出场不提及？
□ POV一致性：全程一个视角，无跳跃？
```
